# Bookworm: Enchanted Library

## Run
Python 3.8+ is required. The game uses only the Python standard library (Tkinter).

```bash
python bookworm_game_enhanced.py
```

## Modes
- **Play**: original word puzzle mode.
- **Worm Arena**: optional pixel-art, word-powered combat mode. Enter a valid 3+ letter word from the built-in dictionary to attack. Longer words deal more damage; combos and critical hits add bonuses. Enemies counterattack, victories restore health, and enemy strength increases by level.

Optional: place `words.txt` beside the script, with one word per line, to extend the built-in dictionary.
